## 📱 AirDrop
* [LocalSend](https://github.com/localsend/localsend) - Free, open-source alternative to AirDrop for Windows, Linux, Android, and iOS over local networks.
* [OpenDrop](https://github.com/seemoo-lab/opendrop) - An open-source Apple AirDrop implementation written in Python that is protocol-compatible with official Apple devices.

## 📺 AirPlay
* [AirPlayServer](https://github.com/xenos1337/AirPlayServer) - A modern, fast AirPlay receiver for Windows supporting real-time video mirroring and audio playback.
* [PhairPlay](https://github.com/mazer666/PhairPlay) - Open-source AirPlay 2 receiver tailored for Android TV and Fire TV devices.

## 🎵 Apple Music
* [Cider](https://github.com) - An open-source, electron-based client for Apple Music available on Windows and Linux.

## 🌐 Apple Protocol
* [open-airplay](https://github.com/openairplay/open-airplay) - A structured collection of libraries built around reversing and interacting with Apple's AirPlay protocol.

## 🛠️ Apple tools
* [libimobiledevice](https://github.com) - A cross-platform software library to communicate with iOS devices natively without iTunes.

## 🏠 HomeKit
* [Homebridge](https://github.com) - A lightweight NodeJS server you can run on your local network that emulates the Apple HomeKit API.

## ☁️ iCloud suite
* [iCloud-Drive-Docker](https://github.com) - A Docker container to synchronize your official Apple iCloud Drive files to Linux local storage.

## 💬 iMessage
* [BlueBubbles](https://github.com) - An ecosystem allowing you to forward and interact with iMessage on Android, Windows, and Linux.

## 💻 Operating Systems
* [Darling](https://github.com) - A translation layer that allows running macOS software applications directly inside Linux environments natively.

## 📦 Other
* [AltServer-Linux](https://github.com) - A practical open-source re-implementation of AltServer built to run natively on Linux servers.
